# hermes-brain v1.0.1 — First Public Release Onboarding

## Goal

Lower the time-to-first-memory for a new Hermes user from "follow the full README" to **<5 minutes**. Ship a demo visual, a guided quickstart, and a clean release cut.

## Audience

Other Hermes users. They already have:
- A Hermes agent host
- Linux + Python 3.11–3.13
- Basic Notion familiarity

They do not have:
- 20 minutes to read
- A pre-built mental model of 7 databases

## Non-goals

- PyPI release (cut when first PyPI question arrives)
- macOS / Windows support (Linux only, by design)
- Standalone CLI (plugin manager install path)
- Interactive `tutorial` command (build cost ≫ value at v1)
- Public demo Notion workspace (drift cost)

## Scope

### 1. Demo visual

- `.github/assets/demo.gif` — 30s, 1280×720, terminal + Notion split.
- Sequence: install → bootstrap → empty Notion page → remember → search → row appears.
- README hero: GIF primary, `hero.png` fallback.
- Transcript block under GIF (captions ≥ TTS/GIF size).

### 2. README "First 5 Minutes"

Placed before "Detailed Installation". 5 numbered steps with expected output:

1. Set `NOTION_API_KEY` and `HERMES_HOME`.
2. `python -m notion_brain url` — confirm the new parent page exists.
3. `from notion_brain import bootstrap; bootstrap.ensure_brain()` — print 7 database IDs.
4. `notion_brain_remember(title="...", content="...", domain="projects")` — print page URL.
5. `notion_brain_search(query="...")` — show the row.

### 3. Common pitfalls block

README short bullets linking to `docs/troubleshooting.md` (already exists):
- Share parent page with integration.
- PEP 668 → `--break-system-packages`.
- `ModuleNotFoundError: agent` → install Hermes.
- Bootstrap ok, no DBs → capabilities.
- Search empty → Notion indexing delay.

### 4. Release polish

- `CHANGELOG.md` with v1.0.0 + v1.0.1 entries.
- Commit staged v1.0.1 work.
- Tag `v1.0.1`, push, verify CI.
- Link `examples/README.md` from main README.
