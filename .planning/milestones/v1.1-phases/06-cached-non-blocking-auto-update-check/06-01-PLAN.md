<objective>
Make the NotionBrainProvider aware of new releases without paying the startup cost. A $HERMES_HOME/.update_cache.json holds the last refresh result with a TTL; provider init reads it synchronously and dispatches a background refresh only when the TTL has expired. health_report() reads the same cache instead of doing its own network call. All network operations stay on the existing daemon worker; no exception escapes when offline.

Output: a new `notion_brain/update_cache.py` (atomic load/save, TTL check, redacted async refresh), `provider.py` and `bootstrap.py` wired to use it, and offline tests.
</objective>
