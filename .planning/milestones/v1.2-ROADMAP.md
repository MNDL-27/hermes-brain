## Overview

After v1.1 finished the distribution + auto-update foundation (PEP 639 metadata, OIDC PyPI publishing, cached non-blocking update check), v1.2 polishes the loose ends called out at the v1.1 closeout:

1. **Update UX (UPD-06, UPD-07 — Phase 7)** — git-clone users currently see "no update available" between formal tags even when they're N commits behind `main`. The CLI must surface commit-level drift, and the printed banner must link to the release-notes URL, not the repository root.
2. **Developer tooling (TOOL-01, TOOL-02 — Phase 8)** — contributors get an opt-in pre-push `pytest -q` hook that fails fast, and a weekly `pre-commit autoupdate` workflow keeps the hook config current without manual intervention.
3. **Test reliability (TEST-HANGS — Phase 8)** — the three pre-existing offline test-suite hangs (`test_coverage_gaps`, `test_migration_privacy_blockers`, `test_provider`) block the full-suite pytest run from being a usable release gate. v1.2 resolves them.

The milestone does **not** change the CLI surface beyond UPD-06/07 rewrites, does **not** touch the Notion schema, and does **not** modify the v1.1 packaging baseline.
