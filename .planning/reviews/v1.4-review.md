## Behavior to review

v1.4 adds a semantic catalog, user-confirmed certification, provenance and graph recall, and an answerability check. It depends on the v1.3 cache, storage adapters and subject-key supersession already on this branch.

The earlier continuation review found passing tests that encoded an incorrect response and missed several integration cases. Commit `fb7ec04` corrects the following scoped behaviors; this table is not proof that all v1.3/v1.4 requirements are complete:

| Area | Before | Now |
| --- | --- | --- |
| Certification | One initialization flag permitted certification throughout the session; truthy values were accepted. | Only boolean `True` supplied by the trusted orchestrator to the current call authorizes certification. Agent arguments and initialization cannot grant permission. |
| Empty catalog coverage | Search and the answerability tool claimed “No certified memory.” | Both identify missing catalog terms and say answerability cannot be verified. |
| Catalog location | Some operations read the environment catalog and saved over the initialized provider's catalog. | Search, glossary, answerability, graph traversal and graph writes use the same provider catalog path. |
| Entity durability | Automatic registration replaced existing entity definitions with empty defaults. | Existing type, description and storage references are preserved. |
| Definition resolution | Exact multiword names could fail the coverage gate; resolved references were only displayed as metadata. | Complete names and synonyms, including phrases, match deterministically; names such as `C++` and `C#` remain distinct. Resolved Notion page/database references select rows from the queried databases even when their text differs. Explicit database filters remain in force. |
| Historical recall | Ordinary supersession omitted graph edges; search could return superseded rows. | Successful supersession records predecessor links and graph edges. If provenance persistence fails, it is logged while cache updates and remaining supersessions continue. Current search excludes superseded rows; history remains available through timeline/related recall. |
| Handoff state | An earlier update replaced pending phases with blanket completion. | The subsequent GSD audit supersedes that update: Phase 9 gap closure is active and Phases 9–15 remain unverified. |
