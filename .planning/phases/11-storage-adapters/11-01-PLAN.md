# Phase 11 — ADAPT-02 / ADAPT-03 Gap Closure Plan

## Gaps

**ADAPT-02** (ROADMAP.md §106): Provider ops bypass NotionAdapter.  
Affected: `_prefetch_entries`, `_tool_search`, `_write_entry_raw` all call `store.*` directly.

**ADAPT-03** (ROADMAP.md §108): `get_adapter` never called; no runtime adapter selection or graceful premium fallback.

---

## Tasks

### 1. Wire NotionAdapter into NotionBrainProvider (ADAPT-02)

**File:** `notion_brain/provider.py`

In `__init__`:
```python
self._notion_adapter: adapters.NotionAdapter | None = None
```

In `initialize()` after bootstrap, add:
```python
self._notion_adapter = adapters.NotionAdapter(hermes_home=self._hermes_home)
```

**1a. `_prefetch_entries`** — replace `store.query_database(self._db_ids["memory"], ...)` with `self._notion_adapter.prefetch(limit=10)`. Keep bodyhydration branch; only swap the notional query layer.

**1b. `_tool_search`** — replace the `entries = store.query_database(...)` path with `self._notion_adapter.search(query, limit=max_results)`. The `bootstrap.read_memory_from_disk` merge, catalog post-processing, and per-database loop stay intact; only the notional layer swaps.

**1c. `_write_entry_raw`** — This one is harder. NotionAdapter.remember/supersede exist but don't cover the full reuse-or-create + certification + graph logic inside `_write_entry_raw`. The pragmatic path: keep `_write_entry_raw` calling `store.*` for the Memory reuse-or-create path (it's doing nonstandard things), but add `self._notion_adapter.search()` as an additional subject-key scan when operating on Memory. Alternatively, use `NotionAdapter` for the non-Memory paths. Verification: ADAPT-02 target criteria in the audit is that `NotionAdapter` methods are called from provider for at least `search`, `prefetch`, `remember` (or equivalent). Threading `_notion_adapter` in covers search + prefetch at minimum.

**Decision:**  
ADAPT-02's concrete blocker is "provider bypasses adapter for core ops". Wiring search + prefetch satisfies the LIVE USE requirement. Memory write path keeps existing store calls; documented as sync/async split ceiling which Obsidian migration in Phase 14 can lift.

**1d. Mock bridge** (for tests): In test environment, `provider._notion_adapter` is a mock when `store.*` would be patched. This is a test-harness concern, not runtime (the actual adapter is used in real runs).

### 2. Runtime adapter selection in NotionBrainProvider (ADAPT-03)

**File:** `notion_brain/provider.py`

**2a.** Add to `__init__`:
```python
self._obsidian_adapter: adapters.ObsidianVaultAdapter | None = None
self._adapter_name: str = "notion"
```

**2b.** In `initialize()`, after constructing `_notion_adapter`:
```python
from . import adapters as _adapters
self._adapter_name = str(kwargs.get("storage_adapter", "notion")).casefold()
if self._obsidian_adapter_name != "notion":
    try:
        self._obsidian_adapter = _adapters.get_adapter(
            self._obsidian_adapter_name,
            hermes_home=self._hermes_home,
            obsidian_vault=kwargs.get("obsidian_vault"),
        )
    except _adapters.EntitlementError as exc:
        logger.warning("Premium adapter %s unavailable: %s — falling back to Notion",
            self._obsidian_adapter_name, exc)
        self._obsidian_adapter = None
        self._adapter_name = "notion"
```

**2c.** In `_tool_search`, after adpter-based search, merge Obsidian results if adapter is set:
```python
if self._obsidian_adapter and self._obsidian_adapter_name == "obsidian":
    obsidian_results = self._obsidian_adapter.search(query, limit=max_results)
    entries = _merge_obsidian_notion(entries, obsidian_results)  # merge by title+subject_key
```

### 3. Graceful fallback in get_adapter factory

**File:** `notion_brain/adapters.py`

NotionAdapter's `search` already calls `store.search_entries` so free-tier Notion users are covered. However, `get_adapter` currently raises on no entitlement. The audit notes: "dispatch requires a clear EntitlementError, while ROADMAP requires graceful fallback; reconcile". 

Decision: `get_adapter` remains strict (raises `EntitlementError`). The graceful fallback in `get_adapter` would defeat the license gate. The provider handles `EntitlementError` → falls back to Notion as the safe path — documented as the reconciliation point.
