<task name="Implement idempotent writes, supersession links and certification" type="auto">
  <files>notion_brain/adapters.py</files>
  <action>
    - `remember`: reuse an exact active match (title + subject key + body) when no id is supplied; update in place when the id exists; otherwise create a new note. Preserve created_at and certified truth on updates.
    - `supersede`: flip every active note for the subject to Superseded (frontmatter + index), link the replacement to the first predecessor via `superseded_page_id`, then write the replacement. Never delete notes.
    - `certify(memory_id, truth="certified")`: update the note and index truth, return the row or None.
    - Route `get_note`, `prefetch` and `search` through the shared row mapper; extend `health` with active/certified counts and schema version.
  </action>
  <verify>
    <automated>.venv/bin/python -m pytest tests/test_adapters.py -q</automated>

  </verify>
  <done>Write semantics match the v1.5 design and existing Obsidian tests remain green.</done>
</task>
