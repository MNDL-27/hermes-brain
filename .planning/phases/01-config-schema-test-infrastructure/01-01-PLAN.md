## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering / Elevation of Privilege | `tests/conftest.py` (`sys.modules`) | medium | mitigate | Populated stubs use `@dataclass(frozen=True)` and negative import tests use `unittest.mock.patch.dict(..., clear=True)` to prevent stub leakage into subsequent test runs (per D-01, D-08). |
| T-01-02 | Information Disclosure | `notion_brain/config_schema.py` (`notionApiKey`) | high | mitigate | Automated unit test enforces `field.default is None` for `KIND_SECRET` fields to guard against hardcoded default credentials (per D-07, SCHEMA-02). |
| T-01-03 | Tampering | `notion_brain/config_schema.py` (`CONFIG_SCHEMA`) | low | mitigate | Container immutability tests assert `isinstance(..., tuple)` for `fields` and `env_fallbacks` ensuring callers cannot mutate configuration definitions at runtime (per D-06, SCHEMA-02). |
| T-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages installed; existing dev dependencies verified via locked `uv.lock` and package legitimacy audit (per ASVS Level 1). |
