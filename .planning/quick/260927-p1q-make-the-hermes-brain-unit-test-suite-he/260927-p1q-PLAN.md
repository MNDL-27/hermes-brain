<objective>
Make the hermes-brain unit test suite hermetic offline: it must complete with no hang and no live-network dependency, enforcing the CLAUDE.md CI-reliability constraint ("Unit tests must run offline without requiring live Notion API credentials or a live Hermes daemon").

Root cause is already diagnosed — do NOT re-investigate it, implement the fix:
`store.get_api_key()` loads NOTION_API_KEY from `$HERMES_HOME/.env`; when a key is present and network egress is denied, `store._request` (store.py:73) blocks on `requests.request(..., timeout=30)` x3 retries instead of fast-failing. Four suites hang or leak: `tests/test_provider.py`, `tests/test_coverage_gaps.py`, `tests/regressions/test_migration_privacy_blockers.py` (all via the store HTTP path or a wrong mock), and `tests/test_packaging.py` (PEP517 build isolation fetches from PyPI — network-bound by design).

Purpose: deterministic, credential-independent, no-hang CI and local test runs.
Output: an autouse socket-deny + env-neutralize fixture, a corrected mock target, a neutralized init-time background refresh, and a registered/deselected `network` marker for the build test.
</objective>
